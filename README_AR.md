# AVIST HOTEL & RESTAURANT — Signature Website 2026

## الملفات
- `index.html` — الصفحة الرئيسية مع SEO وبيانات الفندق.
- `css/styles.css` — كل تصميم الموقع والتجاوب مع الهاتف.
- `js/app.js` — الترجمة والحجز وWhatsApp ومعرض الصور وقائمة المطعم.
- `assets/` — شعار الفندق والصور الحقيقية المضغوطة بصيغة WebP والأيقونات.
- `.nojekyll` — لتسهيل النشر المباشر على GitHub Pages.

## المزايا
- موقع تفاعلي بالتركية والإنجليزية والعربية والفرنسية، مع واجهة عربية RTL.
- صور الفندق الأصلية المرسلة من صاحب المشروع، دون صور فنادق بديلة.
- عرض خيارات الغرف، الجاكوزي والأجنحة مع طلب استعلام عن توافرها.
- نموذج تواريخ الحجز وعدد الضيوف الذي يفتح **نظام الحجز الرسمي Reseliva**.
- زر WhatsApp يحضّر استفسارًا يحتوي تواريخ الدخول والخروج وعدد الضيوف ونوع الغرفة.
- المطعم بالطابق الخامس وقائمة أصناف تفاعلية بالفئات والأسعار المذكورة في الصورة المرسلة.
- معرض صور تفاعلي قابل للتكبير، خريطة Google Maps، الهاتف، البريد الإلكتروني، Instagram وFacebook.
- لا توجد قاعدة بيانات محلية، ولا يتم ادّعاء تأكيد الحجز تلقائيًا.

## طريقة نشر الموقع على GitHub Pages
1. أنشئ مستودع GitHub جديدًا باسم مثل `avist-hotel`.
2. افتح مستودع المشروع ثم `Add file` → `Upload files`.
3. ارفع `index.html` ومجلدي `assets`, `css`, `js` إلى جذر المستودع (root).
4. من `Settings` → `Pages` اختر `Deploy from a branch`، وحدّد `main` و`/(root)`، ثم احفظ.
5. بعد ظهور الرابط افتح الموقع على الهاتف والحاسوب وافحص كل الأزرار.

**مهم:** إذا رفعت محتويات ZIP داخل مجلد إضافي بدل جذر المستودع، فقد لا يظهر الموقع عبر GitHub Pages. يجب أن يكون `index.html` في الجذر.

## التحذيرات قبل النشر الرسمي
- لا توجد أسعار للغرف داخل الموقع، لأن الأسعار والتوافر يتغيّران حسب التاريخ. يحوّل الزر إلى محرك الحجز المرتبط بالموقع الرسمي.
- أسعار المطعم نُقلت من صورة القائمة المرسلة، وقد تكون قديمة؛ راجعها مع إدارة الفندق.
- خدمات السبا والحمام والمساج مذكورة في الموقع الرسمي، لكن ينبغي التأكد من ساعاتها وتوافرها قبل النشر.
- الصور حقيقية ومرسلة من صاحب المشروع، وقد يختلف تصميم الغرفة وتوافر الجاكوزي حسب الفئة.
- هذا الموقع لا يحجز غرفة بشكل نهائي بنفسه؛ الحجز الحقيقي يؤكّده الفندق أو نظام Reseliva.
- نظام خرائط Google المدمج يعتمد على الإنترنت؛ زر «اتجاهات الوصول» يعمل بشكل مستقل عنه.
- يرجى الحصول على موافقة الإدارة على المواد والصور قبل استخدام الموقع بصفة رسمية.
